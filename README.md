# HWO DISRA Notebooks

- https://science.nasa.gov/astrophysics/programs/habitable-worlds-observatory/
- www.habitableworlds.org
- https://hwo.stsci.edu

A repository for Habitable Worlds Explorer DISRA Science case notebooks.

These DISRA Science cases have been implemented using the [hwo_disra](https://pypi.org/project/hwo-disra/)
notebook API to support yield analysis.

## Example Notebook

The [example notebook](hwo_disra_readme.ipynb) demonstrates the use of the `hwo_disra` API
and explanations of developing a `panel 1` and `panel 2` analysis for a science case.

These notebooks can be opened in Google Colab.

1. Go to https://colab.research.google.com/
2. Click `Github >`
3. Authenticate Colab with Github
4. Check the 'Include Private repos' box
5. Paste this repository URL into the search bar `https://github.com/spacetelescope/hwo_disra_notebooks` and search
6. Click on a notebook from the list
7. Notebook will open in Colab
8. **If you have write access to the repository**: `File -> Save` will commit a new version of 
   the notebook to the repo.
